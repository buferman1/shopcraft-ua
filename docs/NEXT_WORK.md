## Правила

Не перебудовувати робоче. Не видаляти дані. Не видавати таблицю чи кнопку за завершену можливість. Реалізація, тестування і deployment — окремі статуси. Без реальних списань/платних планів без окремого дозволу. Недоступні ключі не блокують незалежні модулі. Тестувати ізольованими даними. Звичайні оборотні зміни виконувати самостійно. Не створювати нових інтеграційних обіцянок без перевірки.

## Контрольні збереження

Кожен етап: код + тести + commit + запис фактичної перевірки в PROGRESS.md. Перед завершенням сесії зберегти SHA, стан міграцій, відомі обмеження, наступний конкретний крок. Не зберігати паролі, токени, секретні ключі або дані покупців. Продовження починати з цього файла та PROGRESS.md, а не з повторного створення проєкту.
